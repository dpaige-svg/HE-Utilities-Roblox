# HE-Utilities-Roblox

HE-Utilities is a standalone Roblox Studio security-review plugin that scans
an open place for suspicious signatures, configured keywords and Luau
patterns, risky metadata, UI text, user-ID checks, profanity, and broken
object references.


Signature matching runs locally inside Roblox Studio. HE-Hub, HTTP, and Rojo
are not required for the plugin's local code analysis.
